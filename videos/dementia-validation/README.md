# תיקוף בדמנציה — למה לא להתווכח, לא לתקן ולא לשקר

סרטון אנכי (9:16, ‏1080×1920, ‏60fps, כ-5:30 דק׳) באותו סגנון של סדרת "איך נכון" — עם פתיח ממותג OTTRIX: "כלים להתמודדות עם דמנציה" ומשפט מטרת הסרטון.
- **ההוק**: אמא מבקשת לאסוף את הילדים מהגן (והם כבר הורים); אבא ליד הדלת עם מעיל ותיק, הולך אל אמא שלו שנפטרה; מסבירים → ויכוח → אי שקט. "מוכר לכם?" — מה קורה במוח ומה נכון לענות.
- **המצב**: שלוש התשובות הנפוצות של המטפלת (בבועת דיבור): ויכוח, תיקון המציאות, שקר.
- **פנימה למוח**: היפוקמפוס (למידה וזיכרון) → **הדמיית תלת-ממד של הרקמה** (`lib/neuro3d.js`): תאי עצב מעבירים אותות דרך סינפסות; רבדי בטא-עמילואיד מצטברים בין התאים; סבכי טאו בתוך התאים; האותות נחסמים, הקשרים נקטעים, תאים מתים; ההיפוקמפוס מתכווץ.
- **מה זה אומר**: מידע חדש לא נקלט, זיכרונות ישנים נשמרים לעיתים קרובות → "בעולם שלו, עכשיו זה אז". קדמת המוח (הבלמים) נפגעת → ויכוח לא עובד. האמיגדלה — מערכת האזעקה; מחקר איווה: הזיכרון נמחק, הרגש נשאר; הדבקה רגשית.
- **שלוש התשובות** — מה כל אחת עושה: ויכוח → אזעקה, כעס; תיקון → אבל מחדש; שקר → מרגיע לרגע, שוחק אמון.
- **שיטת התיקוף** (נעמי פייל): נרגעים בעצמנו → מתקרבים בגובה העיניים → נותנים שם לרגש → שואלים עליה (מי, מה, איפה, מתי, איך) → משהו נעים ביחד. במוח: במקום אזעקה — ביטחון. סיכום.
