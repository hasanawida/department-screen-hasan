# סרטון הסברה 2: מעבר לא נכון — סיכון למטפל ולמטופל

סרטון אנכי (9:16, ‏1080×1920, ‏60fps, כ-2:28 דק׳) בעברית, המשך לסרטון על ההמטומה. מעבר ממיטה לכיסא מפורק ל-4 שלבים — **אחיזה ← הרמה ← סיבוב ← הורדה** — ובכל שלב מוצג מה קורה למטפל ולמטופל:
שכבת עמוד שדרה ודיסקים מעל צילום המטפל (העומס בצבעים), מרחק/משקל, פיתול הגו כשהרגליים במקום, פריצת דיסק (הדמיה רפואית), ואצל המטופל: לחץ על עור דק, קרעי עור, שריטות, המטומות, שבר דחיסה בחוליה, ובמקרה הגרוע — נפילה משותפת (שבר בירך, פגיעת ראש). בסוף: "בהמשך נלמד איך נכון".

## מבנה
| קובץ | מה יש בו |
|---|---|
| `script.json` · `facts.md` | הקריינות + כל טענה רפואית ומקורה |
| `assets/` | 13 תמונות מבוימות (AI, ‏Nano Banana Pro דרך Higgsfield) — אותם מטפל ומטופל בכל השלבים + הדמיות רפואיות |
| `scenes/` | 11 סצנות: הוק, שלבים, אחיזה, הרמה, סיבוב, דיסק, רגליים, הורדה, נפילה, סיכום, סיום |
| `lib/photo.js` | Ken Burns על הצילומים + השכבות: שרשרת חוליות ודיסקים צבועה לפי עומס, מפת לחץ, עדשות הגדלה, חצים, סרגל שלבים |
| `sfx.json` · `sfx/` · `tools/mix.py` | עיצוב סאונד מספריות צלילים, מיקס ‎-14 LUFS |
