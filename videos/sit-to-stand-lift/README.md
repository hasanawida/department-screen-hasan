# מעבר נכון 2: מנוף העמדה (Molift Quick Raiser 1)

סרטון אנכי (9:16, ‏1080×1920, ‏60fps, כ-3:44 דק׳) — השני בסדרת "איך נכון".
- **פירוק לשכבות**: המנוף מתפרק מלמטה למעלה — בסיס וגלגלים, משטח לרגליים, תומכי ברכיים, עמוד משופע עם מנוע, זרוע וידיות, רתמת עמידה, לוח בקרה — וכל חלק נדלק בתורו, עם ערימת שכבות בצד. בסוף: עומס עבודה בטוח 160 ק״ג.
- **למי מתאים / למי לא**, ושישה שלבים: בדיקה ← הצבה ← רתמה ← הרמה ← תנועה ← הורדה.
- **קריין** (אבי) מסביר; **המטפלת** (הילה) אומרת את ההכוונה המילולית למטופל — בבועת דיבור (שורות `c*` ב-`script.json`). מטפל אחד מתפעל, השנייה מדברת עם המטופל ומשגיחה.
- פיזור המשקל (רגליים, שוקיים, רתמה) וגב ירוק למטפל; נקודות העור לבדיקה; **למה שניים** — מרכז הכובד זז בסיבוב, המנוף מתנדנד, מטופל כבד דורש יותר כוח, ומטפל אחד לא יכול להשגיח, לנווט ולהכין את הכיסא בבת אחת.
- `facts.md` — ההנחיות ומקורותיהן. התמונות נוצרו ב-AI להמחשה.
