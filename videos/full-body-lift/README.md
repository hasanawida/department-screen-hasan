# מעבר נכון 3: מנוף הרמה (מנוף רצפה נייד עם רתמה)

סרטון אנכי (9:16, ‏1080×1920, ‏60fps, כ-4:07 דק׳) — השלישי בסדרת "איך נכון". המנוף הוא המחשה כללית, לא דגם מסוים.
- **פתיח**: לוגו אשכולות (קבצי הווקטור מאתר הבית), חטיבת טכנולוגיה, ו"למידה בדרך שונה ואחרת — לזקנה איכותית ובטוחה" באותיות זהב תלת-ממדיות (`scenes/s0_brand.js`, `lib/brand.js`).
- **פירוק לשכבות בתלת-ממד** (`lib/hoist3d.js`): בסיס ורגליים שנפתחות, גלגלים ובלמים, תורן, זרוע ומנוע, מוט פיזור וווים, סוללה ושלט, עצירת חירום, רתמה — כל חלק נדלק בתורו, עם תקריבים של הבקרה ושל הרתמה על הווים.
- **למי מתאים**, ו"בכל השלבים: שני מטפלים". שישה שלבים: בדיקה ← גלגול (כולל גלגול לא נכון — משיכה ביד וסיבוב ברגל → המטומה, קרע בעור ושבר — מול גלגול נכון) ← חיבור ← הרמה ← תנועה ← הורדה.
- **קריין** (אבי) מסביר; **המטפלת** (הילה) אומרת את ההכוונה למטופל — בבועת דיבור (שורות `c*` ב-`script.json`).
- מרימים מעט ועוצרים לבדיקה; המשקל מתפזר על כל הרתמה; השוואה מפוצלת: הרמה ידנית (גב אדום) מול מנוף (גב ירוק); נקודות עור לבדיקה; "מטוטלת" — בלי עצירות פתאומיות ובלי סיבוב בתנופה; בלמי המנוף — לפי הוראות היצרן.
- `facts.md` — ההנחיות ומקורותיהן. התמונות נוצרו ב-AI להמחשה.
